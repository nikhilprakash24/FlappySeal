# FlappySeal 🦭

An underwater twist on Flappy Bird featuring a seal with dual-control mechanics.

## Game Concept

- **Theme**: Underwater environment
- **Character**: Seal
- **Controls**:
  - Left tap: Push up (swim upward)
  - Right tap: Nose dive (dive down)
- **Platforms**: Web first, then iOS and Android

## Tech Stack

**Web (Primary)**:
- Phaser 3 - High-performance 2D game framework
- TypeScript - Type-safe development
- Vite - Fast build tool and dev server

**Mobile Conversion**:
- Capacitor - Native iOS/Android wrapper (no Unity needed)
- Progressive Web App (PWA) capabilities

## Why This Stack?

1. **Phaser 3**: Production-ready, used by thousands of games, excellent performance
2. **Capacitor**: Official Ionic framework for converting web apps to native mobile
3. **No Unity Required**: Direct conversion from web to mobile with native performance
4. **Easy Deployment**: Can deploy web version instantly to see live
